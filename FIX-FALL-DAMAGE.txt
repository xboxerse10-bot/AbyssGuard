AbyssGuard 26.3 - Fall damage fix

Added Fabric ServerLivingEntityEvents.ALLOW_DAMAGE callback for DamageTypes.FALL.
Checks the player's landing position against regions, highest priority first.
FALL_DAMAGE=deny cancels fall damage for all players, including OP/staff.
FALL_DAMAGE=allow or no applicable rule allows normal fall damage.

Upload all contents of AbyssGuard-main to the GitHub repository root and run Actions build.
This source patch has NOT been compiled locally; GitHub Actions will validate API compatibility.
